# Altair Python Lab

Учебная лаборатория прикладных и квантовых вычислений на Python для школьников, выполняющих проекты в Детском технопарке «Альтаир» РТУ МИРЭА.

Репозиторий содержит самостоятельные программы, демонстрирующие математические модели, алгоритмы, квантовые схемы, обработку сигналов и разработку вычислительных веб-приложений. Примеры предназначены для изучения, модификации и использования отдельных технических решений в собственных проектах.

## Содержание

| Раздел | Темы |
| --- | --- |
| [01_environment](01_environment/) | Основы работы с Python, массивы NumPy, построение графиков |
| [02_graphs](02_graphs/) | Графы, кратчайший путь, алгоритм Дейкстры, обход заданных точек |
| [03_optimization](03_optimization/) | Бинарные переменные, задача о рюкзаке, MaxCut, QUBO |

## Требования

- Python 3.11 или 3.12 (рекомендуется 3.12).
- Visual Studio Code с расширениями Python и Python Debugger от Microsoft.
- Git — для клонирования репозитория и работы с версиями кода.
- Доступ в интернет при первоначальной установке зависимостей.

Основные библиотеки проекта:

| Библиотека | Назначение |
| --- | --- |
| NumPy | Работа с массивами и численные вычисления |
| Matplotlib | Построение графиков и диаграмм |
| NetworkX | Работа с графами и маршрутами |
| Qiskit | Построение и преобразование квантовых схем |

| Streamlit | Создание интерактивных веб-приложений на Python |

## Установка и настройка

Команды ниже приведены для Windows и PowerShell в терминале VS Code.

### 1. Получение исходного кода

```powershell
git clone https://github.com/DNKlyosov/altair-python-lab.git
cd altair-python-lab
```

Откройте папку проекта в VS Code (`File → Open Folder`). Если команда `code` доступна в терминале, можно выполнить `code .`.

Вместо клонирования можно скачать архив репозитория через `Code → Download ZIP` на GitHub и распаковать его.

### 2. Создание виртуального окружения

В терминале, открытом в корневой папке проекта, выполните:

```powershell
py -3.12 -m venv .venv
```

Если установлен Python 3.11, используйте `py -3.11 -m venv .venv`. Если команда `py` недоступна, проверьте версию через `python --version` и выполните `python -m venv .venv`.

### 3. Установка зависимостей

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Виртуальное окружение создаётся локально на каждом компьютере. Активировать его для приведённых команд необязательно.

### 4. Выбор интерпретатора в VS Code

Нажмите `Ctrl+Shift+P`, выберите `Python: Select Interpreter` и укажите интерпретатор `.venv\Scripts\python.exe`.

### 5. Проверка установки

```powershell
.\.venv\Scripts\python.exe 01_environment/01_hello.py
```

## Запуск программ

Все команды выполняются из корневой папки репозитория. Каждый пример можно изучать отдельно.

```powershell
# Массивы и численные вычисления
.\.venv\Scripts\python.exe 01_environment/02_numpy.py

# Поиск кратчайшего пути
.\.venv\Scripts\python.exe 02_graphs/02_shortest_path.py

# Задача о рюкзаке
.\.venv\Scripts\python.exe 03_optimization/02_knapsack.py

# Транспиляция квантовых схем
.\.venv\Scripts\python.exe 04_quantum/04_topology.py

# Алгоритм Гровера
.\.venv\Scripts\python.exe 04_quantum/05_grover.py

# Спектральный анализ сигнала
.\.venv\Scripts\python.exe 05_signals/02_fft.py

# Измерение времени и экспорт результатов
.\.venv\Scripts\python.exe 07_debugging/02_export.py
```

Программы с Matplotlib могут открывать отдельное окно графика. Закройте его, чтобы завершить выполнение программы.

## Веб-приложения

**Интерактивная маршрутизация:**

```powershell
.\.venv\Scripts\python.exe -m streamlit run 06_web/app.py
```

**Визуализатор кубита:**

```powershell
.\.venv\Scripts\python.exe -m streamlit run 06_web/quantum_app.py
```

Откройте адрес, указанный в терминале (обычно `http://localhost:8501`), если браузер не открылся автоматически. Для остановки приложения нажмите `Ctrl+C` в терминале.

В примере маршрутизации интерфейс (`app.py`) отделён от расчётной логики (`engine.py`). Такая организация позволяет использовать вычислительные функции независимо от веб-интерфейса.

## Отладка и тестирование

Для пошагового выполнения откройте Python-файл, установите точку останова клавишей `F9` и запустите конфигурацию `Python: текущий файл` через `F5`. Клавиша `F10` позволяет перейти к следующей строке без входа в вызываемую функцию.

Запуск автоматических тестов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Если установка квантовых библиотек недоступна, для работы с классическими консольными примерами можно отдельно установить:

```powershell
.\.venv\Scripts\python.exe -m pip install numpy matplotlib networkx
```

При отсутствии Qiskit соответствующий тест пропускается; квантовые примеры требуют установки квантовых библиотек, а веб-приложения — Streamlit.

## Работа с Git

В репозитории хранятся исходные программы, список зависимостей, задания и общая конфигурация отладчика. Виртуальное окружение `.venv/`, кэш Python, локальные настройки и сгенерированные результаты `results/` не предназначены для публикации и исключаются правилами `.gitignore`. Папка `results/` создаётся автоматически при экспорте данных.

Для самостоятельных изменений используйте собственный форк репозитория или локальную ветку. Например:

```powershell
git switch -c practice/shortest-path
# Внесите изменения в выбранный файл
git status
git add 02_graphs/02_shortest_path.py
git commit -m "Update shortest path example"
```

## Ограничения

Программы являются учебными примерами, а не готовыми специализированными системами. Квантовые вычисления выполняются на симуляторах; подключение к физическому квантовому компьютеру не требуется. Результаты моделирования сами по себе не доказывают квантового ускорения.

Классические демонстрации прошли первичную проверку запуска. Полная проверка квантовых и веб-примеров в исходной среде подготовки не выполнена из-за недоступности соответствующих зависимостей. Диапазоны версий указаны в `requirements.txt`; точный набор версий не зафиксирован lock-файлом.
